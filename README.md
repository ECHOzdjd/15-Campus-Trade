## 项目简介

**校园二手交易平台**是一款面向在校大学生的移动端响应式 Web 应用，旨在解决校园内闲置物品流通问题。用户可以发布二手书籍、电子产品、生活用品等闲置商品，也可以浏览、搜索并联系卖家完成交易。平台支持商品分类浏览、关键词搜索、收藏夹、即时消息通知等功能，帮助同学们以更低成本获取所需物品，同时减少校园资源浪费。目标用户为全体在校大学生，尤其适合毕业季物品转让和开学季二手教材交易场景。

## 技术栈（初步规划）

- **前端：**
  - 框架：Vue 3 + Vite
  - UI 组件库：Vant（移动端适配）
  - 状态管理：Pinia
  - HTTP 请求：Axios
  - 响应式布局：CSS Flexbox / Grid + rem 适配

- **后端：**
  - 运行环境：Node.js
  - 框架：Express.js
  - 身份认证：JWT（JSON Web Token）
  - 文件上传：Multer（商品图片上传）
  - API 风格：RESTful API

- **数据库：**
  - 主数据库：MySQL 8.0（存储用户、商品、订单等结构化数据）
  - 缓存：Redis（Session 缓存、热门商品缓存）
  - 文件存储：本地存储 / 阿里云 OSS（商品图片）
