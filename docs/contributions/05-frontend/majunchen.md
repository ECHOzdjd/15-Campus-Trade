## 遇到的问题和解决方案

### 1. Element Plus 主题定制
**问题**：Element Plus 默认主题与 Linear 深色风格差异较大  
**解决**：通过 CSS 变量和 SCSS 变量覆盖，保留组件功能的同时实现视觉定制

### 2. 图片上传流程
**问题**：图片需要先上传到服务器再获取 URL  
**解决**：封装 ImageUploader 组件，内部处理上传逻辑，对外暴露 URL 数组，支持 v-model 双向绑定

### 3. 响应式布局
**问题**：商品卡片在不同屏幕尺寸下显示不一致  
**解决**：使用 CSS Grid 和媒体查询实现响应式列数调整（桌面 3 列、平板 2 列、手机 1 列）

### 4. 分页组件兼容性
**问题**：Element Plus 分页组件的 v-model 语法在某些版本中不支持  
**解决**：改用 `:current-page` 和 `@current-change` 事件绑定
