## 遇到的问题和解决

1. 问题：项目原来的健康检查只有 `{ code, message }`，不能体现版本和运行时间。
   解决：扩展健康检查响应，加入 `status`、`timestamp`、`version` 和 `uptimeSeconds`。

2. 问题：原来的开发态日志不方便机器解析。
   解决：改成统一 JSON 日志，并增加请求 ID，方便按请求排查问题。

3. 问题：项目没有独立指标接口。
   解决：先用进程内存保存基础指标，满足本地调试和作业验收要求。
