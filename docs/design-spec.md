# 设计说明

## 项目概述
**校园二手交易平台** - 一个为校园用户提供二手物品买卖、交流的平台。用户可以浏览商品、发布商品、管理订单和个人信息。

## 配色方案

- **主色：#4F6EF7** - 蓝紫色，用于主要交互元素、按钮、导航等
- **辅助色：#FF6B35** - 橙黄色，用于价格标签、重要提示等
- **背景色：#ffffff** - 纯白色，页面主背景
- **中和色：#ececf0** - 浅灰色，用于边框、分割线、禁用状态
- **强调色：#d4183d** - 深红色，用于删除、错误、警告提示
- **文字色：#030213** - 深黑色，主要文字颜色
- **辅助文字：#717182** - 灰色，子文本、时间戳等

## 字体

- **标题字体**：系统默认字体堆栈（-apple-system, BlinkMacSystemFont, 'Segoe UI'）
- **正文字体**：同上
- **字体权重**：
  - 标题：600-700 (bold/font-bold)
  - 正文：400 (normal/font-normal)
  - 强调：500 (medium/font-medium)
- **基础字体大小**：16px

## 核心页面

### 1. 首页 / 产品列表页（ProductListView）
**功能**：
- 展示所有二手商品的列表
- 支持搜索、过滤商品
- 商品卡片展示，包含：图片、标题、价格、卖家、发布时间、状态标签
- 响应式网格布局

**关键设计**：
- 卡片式布局，支持hover放大效果
- 价格用橙色突出显示
- 商品状态（出售中/已售出/已下架）用不同Badge颜色区分
- 搜索框固定在顶部导航栏

### 2. 产品详情页（ProductDetailView）
**功能**：
- 详细展示单个商品信息
- 展示商品的多张图片（轮播）
- 显示卖家信息、评价
- 提供购买/咨询/收藏操作
- 展示商品描述、参数等

**关键设计**：
- 大图展示主商品图片
- 轮播显示所有图片
- 两栏布局：左侧图片，右侧信息
- 醒目的购买按钮

### 3. 发布/编辑商品页（ProductPublishView）
**功能**：
- 上传商品图片
- 输入商品信息（标题、描述、价格、分类等）
- 图片裁剪、排序功能
- 保存为草稿或发布
- 支持编辑已发布的商品

**关键设计**：
- 表单式布局
- 图片上传区域突出
- 实时预览
- 步骤提示

### 4. 登录页（LoginView）
**功能**：
- 账号/密码登录
- 记住密码选项
- 链接到注册页
- 忘记密码链接

**关键设计**：
- 简洁式布局，居中显示
- 统一的表单风格
- 清晰的行动号召(CTA)

### 5. 注册页（RegisterView）
**功能**：
- 学号/邮箱注册
- 密码设置
- 验证码验证
- 阅读并同意协议

**关键设计**：
- 与登录页保持一致的风格
- 分步表单或单页面表单
- 清晰的验证反馈

### 6. 订单列表页（OrderListView）
**功能**：
- 展示用户的所有订单
- 支持按状态筛选（待发货、配送中、已完成等）
- 显示订单摘要信息
- 点击进入订单详情

**关键设计**：
- 列表或卡片式布局
- 订单状态清晰标注
- 快速操作按钮

### 7. 订单详情页（OrderDetailView）
**功能**：
- 展示订单完整信息
- 显示物流追踪
- 仅能查看和跟踪订单
- 评价功能（如果已完成）

**关键设计**：
- 时间线展示物流状态
- 清晰的订单信息分组
- 快捷操作按钮

### 8. 个人中心页（ProfileView）
**功能**：
- 显示个人信息（头像、昵称、学号等）
- 账户设置
- 地址管理
- 登出功能

**关键设计**：
- 头部用户卡片
- 设置列表分组显示

### 9. 我的商品页（MyProductsView）
**功能**：
- 展示用户发布的所有商品
- 按状态分类显示
- 支持编辑、下架、删除商品
- 快速发布新商品按钮

**关键设计**：
- 与首页保持一致的卡片风格
- 操作按钮醒目

## 交互说明

### 导航流程
- **首页** → 点击商品卡片 → **产品详情页**
- **首页** → 点击"发布商品"按钮 → **发布商品页**
- **首页** → 点击"我的商品" → **我的商品页**
- **首页** → 点击购物袋图标 → **订单列表页**
- **产品详情页** → 点击卖家信息 → **卖家主页**（或回到列表）
- **订单列表页** → 点击订单 → **订单详情页**
- **个人中心** → 点击"我的商品" → **我的商品页**

### 用户交互

#### 搜索功能
- 在通用导航栏搜索框输入关键词 → 按回车或点击搜索按钮
- 过滤产品列表展示搜索结果

#### 商品图片预览
- 产品详情页支持轮播图片切换
- 点击缩略图快速切换
- 放大镜功能查看细节（可选）

#### 状态变化
- 商品发布后，实时显示在首页
- 订单状态变化实时通知用户
- Toast提示重要操作反馈

#### 下拉刷新
- 首页列表支持下拉刷新，重新加载商品列表
- 订单列表支持下拉刷新，更新订单状态

#### 收藏/关注
- 产品详情页可收藏商品（已登录用户）
- 已收藏商品标记为已收藏状态
- 个人中心可查看收藏列表

#### 导出与分享
- 可分享商品链接到社交媒体（可选）
- 导出订单为PDF（可选）

## 响应式设计

- **桌面版 (≥1024px)**：多列网格布局，完整功能显示
- **平板版 (768px-1023px)**：两列网格布局
- **移动版 (<768px)**：单列布局，优化触屏交互

## 无障碍设计

- 所有交互元素支持键盘导航
- 图片添加 alt 文本
- 颜色不是唯一的信息传递方式
- 对比度满足 WCAG AA 标准

## 组件库规范

项目使用 **Radix UI** 和 **shadcn/ui** 组件库，包含：
- Badge（状态标签）
- Button（按钮）
- Input（输入框）
- Select（下拉选择）
- Dialog（模态框）
- Dropdown Menu（下拉菜单）
- Tabs（标签页）
- Avatar（头像）
- Card（卡片）
- 等数十个UI组件

所有组件均支持自定义样式，基于 Tailwind CSS。

## 性能考虑

- 图片使用适当压缩和格式（WebP）
- 使用虚拟滚动处理长列表
- 组件懒加载优化首屏加载
- 缓存商品图片和用户数据
